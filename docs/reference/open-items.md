# Open items

Decisions not yet made and facts not yet confirmed. Each one should become a
mission, an ADR, or a line in a reference doc — not stay here. An item that is
answered is removed, and its number is not reused: the gaps in the numbering are
closed items, and an ADR that cites one says what answered it.

The **Before the repository is published** section at the bottom is separate:
those are not open questions but known work that has to land before this
repository is made public.

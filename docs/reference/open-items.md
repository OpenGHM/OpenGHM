**Done:** P2 (the personal-email exposure — the seed that carried real names/emails was deleted rather than scrubbed, since it was the `datasets` collection's only writer; see item 13 above and [gateway.md §4](../architecture/gateway.md#4-where-state-lives) — and the three spec examples now use fictional creators), P3 (`Config.account` and `_ANVIL_APPS_WBM` have no baked-in value any more — the real ones now live in `ops/docs/reference/anvil-environment.md` for this team to set locally; the `--preset anvil` init preset, the interactive prompt's example text, and all six golden fixtures were also cleaned), P4 (dev logins no longer reach the client bundle, moved server-side), P6 (LICENSE, CONTRIBUTING.md, SECURITY.md, .github/CODEOWNERS added), P7 (rule 4 corrected to say codegen is the target and hand-maintenance is the current reality — Next item 3 is still the generator itself), P8 (`docs/tools/README.md` corrected to the four checks that exist).

Open item 13 above is the resulting gap: nothing populates `datasets` any more, for anyone.

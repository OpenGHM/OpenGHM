This page is hand-written, not fetched or generated — it transcribes schemas/*-spec/index.json and schemas/*-spec/layout/*.json directly and must be updated by hand in the same commit as either changes (the same rule AGENTS.md rule 4 states for every hand-maintained view of the spec, until a generator exists for this too). generated/ is the one part of this directory that regenerates on its own — run just schema-docs-gen after any metadata.json change and commit the result.
